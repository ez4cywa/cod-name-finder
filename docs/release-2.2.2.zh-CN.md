# 2.2.2 首次公开发行

日期：2026-10-05。许可证：MIT。

本版提供 Windows x64 EXE 安装包、完整源码及随包中文教程。Avalonia NativeAOT 界面配合内置 Python 后端，普通使用无需安装 Python、.NET 或原始研究项目。GPU 计算需要本机提供兼容 OpenCL 驱动；没有 GPU 时可用 CPU。

界面视觉参考 [LiquidGlassAvaloniaUI](https://github.com/KaranocaVe/LiquidGlassAvaloniaUI)：透明玻璃、圆角折射、高光边缘和蓝 / 玫红 / 橙色背景。使用其 MIT 维护分支 Fluid.Avalonia.Acrylic 完成 NativeAOT 下的实际 Skia 渲染。

## 本版功能

- 导入已导出的哈希资产，按作品与名称域生成候选、计算哈希并验证命中；模型不作为破解目标，材质可排除。
- 根据已命名的相关资产探索动画和声音名称；关键词在命中后筛选结果。
- 自动排除本机 Saluki 已有名称，输出新增 CSV、CDB 与分类索引；准备合并目录供用户加载。
- BO7 / COD2026 捕获面板可选择本地目录中的 BAT，支持刷新、中文和空格文件名及按作品选择默认脚本。
- 直接运行所选 BAT，通过 Windows Job 核对实际加载器归属；结束或停止时清理本次启动的进程。
- 完整捕获后自动选择离线快照，之后可在另一台电脑计算；教程可由界面按钮或 F1 打开。

## 已验证结果

- 524 项 Python 测试及 15 项 NativeAOT Core 自检通过。
- BAT 原生集成测试覆盖中文路径、交互、多行脚本、异步子进程、失败清理和外部进程保留；GUI 协议测试覆盖读取、默认 BAT、自选 BAT 和取消。
- 新版本地 Cordycep CLI 的 COD2026 Beta 经真实 BAT 启动；独立复核 414 项类型表、512 个 40 字节池记录及 96 字节节点前缀。
- 打包后的 GUI 在隔离运行依赖环境中捕获 337,958 条原始记录、43,105 条候选字符串；已适配的 16 个资产池两次读取一致。
- 对该快照执行一百万候选预算的动画计算：28,826 个验证命中，排除 28,294 个 Saluki 现有名称，得到 532 个新增名称。新增项逐条独立复算、核对 40 个现有索引，并由独立 Rust CDB 读取器检查输出。
- EXE 安装、卸载、CPU/GPU 计算、UTF-8 错误消息、离线快照、教程和用户文件保留检查通过。

测试表样例使用原创合成名称与独立参考预期值。实际游戏资产、社区完整名称数据库、本机授权文件和私人验证输出由用户自行提供，不在公开源码或发行附件内。

## 当前边界

本次捕获针对 BAT 加载的 common 集合，不证明全游戏已加载。名称计算达到候选预算后为 `partial`，不证明全部名称被穷举。

BO7 已登记静态版本组合，但本机真实启动未返回可核对的完成提示，原因尚未确认；不计为现场成功。未知加载器、配置或转储指纹不会自动套用旧布局。

Saluki 输出格式已用独立读取器验证，尚未完成 Saluki 界面实际加载验收、第二台物理电脑测试或八小时持续运行测试。
