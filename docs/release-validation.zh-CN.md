# 本地发布验证记录

版本 1.0.2，2026-10-02，Windows 11 x64。仅本地发布，不公开上传。

- 19 项自动测试通过，包括恢复、前作复用、冲突排除、截断键限制、导出格式和 GUI 状态。
- 18 个哈希配置，108 组独立 C++ 参考向量，Python / Rust CPU / OpenCL GPU 逐项一致。ASCII 范围有参考证据，非 ASCII 目标需另行核验。
- 真实目录含 769570 项资产；已有名称用于算法校准。20 项隐藏已知音频名称通过同族候选发现，20/20 恢复；此结果不是任意未知名称恢复率。
- 500 对实际已导出音频路径及目标名称通过哈希对应检查。反斜杠展平不能唯一逆转，按有限候选路径验证。
- 验证导出 826 个关键词相关非模型名称，包含已有与复用名称，不是 826 个新发现。
- 独立 Rust 读取导出 CDB 与 Python 结果一致；读取 40 个现有 Saluki CDB；准备合并输出而不修改 Saluki 安装目录。
- CPU/GPU 测试机器 GPU 为 NVIDIA RTX 5090。20 万候选测试中计入初始化开销后 CPU 更快；自动模式会考虑此开销。

## 已知边界

哈希不能直接逆算为唯一真实名称，软件生成词典/关键词/模板候选并精确比较。低60位命中和异名冲突不进入正式导出。作品、名称域、完整位宽要分别选择。

COD2026 的资源规则有本地已知名称证据；脚本、Dvar、Omnvar 等未证实域不冒用前作规则。BO4—BO7、MW2019—MWIII 等公开名称算法的覆盖与来源见 hash-algorithm-coverage.md。

打包程序使用独立进程从源码目录外检查 CPU/GPU、前作复用、CDB 与 GUI 启动，机器可复验记录存于 validation/packaged-validation.json。尚未完成 Saluki 界面实际加载验收与8小时持续运行测试，不将这两项记为通过。便携版要求 Windows 11 x64 和 GPU 对应 OpenCL 驱动；无可用 GPU 时采用 CPU。

## 1.0.1 Saluki 增量导出

导出自动读取安装目录所有 CDB，对完整哈希键已有非空名称的条目进行排除。CSV、CDB、分类索引、证据均保持相同新增集合；同键旧名称不同也排除。索引不存在或损坏则停止导出，全部已有时输出空增量及排除报告。真实 mike4 筛选验证：剩余 86 项，排除 740 项，读取 40 个索引。原始安装目录未修改。
